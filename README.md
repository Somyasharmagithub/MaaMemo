# MaaMemo ❤️
### Every Voice Carries a Story.

**A voice-first AI-powered memory book that helps preserve personal stories, experiences, and precious family memories.**

🌐 **Live Application:** https://maamemo-frontend.onrender.com/  
💻 **GitHub Repository:** https://github.com/Somyasharmagithub/MaaMemo

---

## 💭 The Idea

Every family has stories worth remembering. Stories from childhood, life experiences, family traditions, and moments shared by generations.

But not every story gets written down. Many are simply forgotten with time.

**MaaMemo aims to change that.**

It provides a simple way to capture memories through voice, turn recordings into text, organize them, and listen to them again through AI-generated narration.

The idea is to make preserving memories as natural as having a conversation.

## ✨ What MaaMemo Offers

- 🎙️ **Voice Memory Capture** — Record or upload audio memories.
- 📝 **Smart Transcription** — Convert spoken memories into text.
- 💾 **Memory Collection** — Save, edit, and manage personal memories.
- 🔍 **Search & Filter** — Find saved memories whenever you need them.
- 🔊 **AI Narration** — Listen to saved memories through generated speech.
- 🎧 **Original Audio Playback** — Revisit the original recordings.
- 📅 **Monthly Recap** — Revisit memories captured throughout the month.

## 🤖 Powered by Gnani AI

Gnani AI's speech technologies power the core voice experience of MaaMemo.

| Model | Capability | How MaaMemo Uses It |
|---|---|---|
| **Prisma** | Speech-to-Text | Converts voice recordings into written memories |
| **Timbre** | Text-to-Speech | Generates narration from saved memories |

Together, these models enable users to preserve stories in spoken form and experience them again through AI-generated voice.

## ⚙️ Technology Stack

- **Frontend:** React, JavaScript, Vite, CSS
- **Backend:** Python, FastAPI
- **Database:** SQLite, SQLAlchemy
- **AI:** Gnani AI Prisma and Timbre
- **Deployment:** Render
- **Version Control:** Git and GitHub

## 🔄 How It Works

1. Record or upload a voice memory.
2. Convert the recording into text using Gnani AI Prisma.
3. Save and organize the memory.
4. Search and revisit saved memories.
5. Generate spoken narration using Gnani AI Timbre.
6. Listen to the memory again.
